# Better Journal UI by Najane

A small UI mod for Civilization VII that puts a permanent, semi-transparent background behind the
**Journal** (`quest-list`) - the block of tracked goals under the tech/civic buttons on the left of
the HUD - so it stays readable over the map.

The background is a gold frame with concave cut-in corners over the same gradient the game draws
behind a **hovered** journal entry - or, with **Solid background** on, solid dark navy. Both are in
**Options → Mods → Najane Mods: journal**; the opacity slider (0-100 %, default 90 %) fades the
fill only, and 0 turns the whole thing off.

## How it works

| File | Scope | What it does |
|---|---|---|
| `ui/options/journal-background-options.js` | game + shell | the stored setting and its slider |
| `ui/options/najane-mod-options-registry.js` | game + shell | shared verbatim with the other Najane mods - keeps their option sections adjacent (`sort: 40` here) |
| `ui/journal-background.js` | game | one `<style>` in `document.head`, rewritten when a setting changes |
| `ui/journal-hide-empty.js` | game | decorates `quest-list` and hides it entirely while it shows no quest |
| `texture/*.png` | game (`ImportFiles`) | the notched frame and the two fills, generated by `tools/make-textures.py` (Pillow) |

No patched game file: the background rule targets `quest-list .quest-item-container` by
element name and the component's own class. See `game-files-snapshots/` for the game files it
depends on.

## Deploy

```bash
./deploy.sh
```

Then enable the mod in *Additional Content → Mods* (a new mod is not enabled by default), and
return to the main menu or restart. `Logs\UI.log` shows `journal-background: loaded`.

## Conventions

Same as the sibling mods: everything written to a file is in English except Polish content in
`text/pl_PL/`; `console.log` never reaches `UI.log`, so everything uses `console.error`;
`node --check` is useless on ES modules - `deploy.sh` checks with `--input-type=module` instead.
